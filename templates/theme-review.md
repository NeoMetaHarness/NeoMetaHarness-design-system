# Neo theme review

## Tokens
Record affected semantic token, its current Astryx value, desired reasoned adjustment, and both light/dark results. Avoid component-level hardcoded colors.

## Matrix
| Check | Light | Dark |
| --- | --- | --- |
| Body text contrast | verified against design target | verified against design target |
| Focus indication | visible by keyboard | visible by keyboard |
| Hover/press states | clear without motion | clear without motion |
| Error and success | text plus visual cue | text plus visual cue |
| Disabled controls | legible and non-interactive | legible and non-interactive |

## Ship criteria
Check responsive layouts, reduced-motion preferences, and documentation examples. Update the theme package and examples in one reviewed change.
